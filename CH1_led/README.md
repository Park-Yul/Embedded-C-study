# STM32 버튼 입력 기반 LED 제어

STM32F411 마이크로컨트롤러에서 **버튼 3개로 LED 4개의 점등·소등·점멸을 제어**하는 임베디드 C 프로젝트입니다. STM32CubeMX에서 입출력 핀과 시스템 클록을 설정하고, STM32 HAL로 버튼 입력을 읽어 LED의 동작을 전환했습니다.

## 주요 기능

| 버튼 입력 | LED 동작 |
| --- | --- |
| `PC0` | LED 4개를 켜고 점멸을 해제합니다. |
| `PC1` | LED 4개를 끄고 점멸을 해제합니다. |
| `PC3` | LED 4개의 출력을 약 200 ms마다 반전합니다. 버튼을 놓아도 점멸을 유지합니다. |

## 구현 방식

- **GPIO 설정** · `PC0`, `PC1`, `PC3`을 버튼 입력으로 구성하고, `PB13`, `PB14`, `PB15`, `PC4`를 LED 제어용 푸시풀 출력으로 구성했습니다. LED 출력은 초기화 시 모두 Low로 설정합니다.
- **입력 처리** · 메인 루프에서 버튼 입력을 반복해서 읽고, Low를 눌림으로 판단합니다. 여러 버튼이 동시에 눌리면 점등, 소등, 점멸 순으로 우선 처리합니다.
- **점멸 상태 유지** · 상태 변수로 점멸 여부를 기억합니다. 점멸 중에는 네 출력의 상태를 함께 반전한 뒤 `HAL_Delay(200)`으로 대기합니다. 다음 버튼 입력은 이 대기가 끝난 후 읽습니다.

## 개발 환경과 주요 파일

| 항목 | 내용 |
| --- | --- |
| 마이크로컨트롤러 | STM32F411RET6, Arm Cortex-M4 |
| 개발 환경 | C, STM32CubeIDE, STM32CubeMX, STM32F4 HAL |
| 클록 설정 | 8 MHz 외부 오실레이터(HSE)와 PLL을 사용해 시스템 클록을 100 MHz로 설정 |
| [Core/Src/main.c](Core/Src/main.c) | 초기화, 버튼 입력 처리, LED 제어 로직 |
| [CH1_led.ioc](CH1_led.ioc) | GPIO 핀 배치와 클록 설정 |

## 보드에서 확인하는 방법

1. STM32CubeIDE에서 `CH1_led`를 기존 프로젝트로 가져와 빌드합니다.
2. 프로젝트의 핀 배치와 클록 설정에 맞는 보드를 SWD로 연결하고 펌웨어를 올립니다.
3. 세 버튼을 각각 눌러 점등, 소등, 점멸을 확인합니다. 점멸 버튼을 놓은 뒤에도 점멸이 유지되고, 점등 또는 소등 버튼을 누르면 중단되는지 확인합니다.

> [!NOTE]
> 버튼 입력은 내부 풀업을 사용하지 않습니다. 외부 회로에서 버튼을 놓았을 때 High, 눌렀을 때 Low가 유지되도록 구성해야 합니다. LED는 출력이 High일 때 켜지는 배선을 기준으로 합니다.
